# 练习图判断标准说明

## 一、先看对照图（5 类并排）

对照图从左到右：
- **OK**：元件完整且位置正确
- **Missing Part（缺件）**：有焊盘/底座，但元件没装上
- **Shifted（偏移）**：元件装上了，但位置歪了/没对准焊盘
- **Foreign Object（异物）**：板上多出来不该有的东西（黑点）
- **Scratch（划痕）**：板面有划伤线条

## 二、每类详细判断标准

### 1. OK（正常）
- 板上有 3~5 个元件
- 黑色芯片、黄色电阻、棕色电容都在各自位置上
- 元件和焊盘/底座对齐，没有明显歪斜
- **板上没有额外的黑点或划伤**
- 判定：分类选 `OK`

### 2. 缺件（Missing Part）
- 板上有**一个白色描边的矩形框（空焊盘占位）**，四个角有小锡点
- 这个框里**没有任何元件**（没有黑芯片、没有棕电容、没有黄电阻）
- 这就是"该装元件的位置空着了"
- 判定：分类选 `缺件`

> 区分要点：**白色框里是空的** = 缺件；**白色框里有黑色/黄色元件** = 不是缺件（那是 OK 或偏移）。

### 3. 偏移（Shifted）
- 元件**存在**，但**没对准焊盘**
- 常见表现：黑色芯片的一边已经离开黄色焊盘，悬空或歪到旁边
- 判定：分类选 `偏移`

> 判断口诀：**"有件，但歪了"** → 偏移

### 4. 异物（Foreign Object）
- 所有元件可能都是正常的
- 但板上某处有一个**黑色小圆点**（或其他颜色的小点）
- 这个点不是元件、不是焊盘、不是走线
- 判定：分类选 `异物`

### 5. 划痕（Scratch）
- 所有元件可能都是正常的
- 但板上有一条**浅灰色/白色的细线**，像被划伤
- 判定：分类选 `划痕`

## 三、判断决策流程（按顺序看）

```
第1步：看有没有元件没装上？
        → 有焊盘/底座但空着 → 缺件
        → 否，继续下一步

第2步：看元件有没有歪？
        → 元件在，但离开焊盘/没对齐 → 偏移
        → 否，继续下一步

第3步：看板上有没有黑点？
        → 有不该出现的小黑点 → 异物
        → 否，继续下一步

第4步：看板上有没有灰白线条？
        → 有划伤线 → 划痕
        → 否 → OK
```

## 四、标注时要做的三件事

每张图你都需要完成三个动作：

1. **分类（Choices）**
   - 从 `OK / 缺件 / 偏移 / 异物 / 划痕` 中选一个
   - 用上面的决策流程判断

2. **画检测框（Rectangle Labels）**
   - 框出图中的**黑色芯片**，标签选 `元件`
   - 黄色电阻和棕色电容暂时不用框（重点练芯片框）

3. **OCR 文字（TextArea）**
   - 元件附近的丝印文字，如 `U1`、`R3`、`C1`、`Q5`、`L1` 等
   - 挑一个清晰的写上即可，没有就不写

## 五、常见疑问

**Q：一张图里既有偏移又有划痕怎么办？**
A：按最显眼的那个缺陷分类。本练习数据里每张图只含一种缺陷，不用纠结多标签。

**Q：黄色电阻和棕色电容要不要框？**
A：这次练习主要框**黑色芯片**，标签用 `元件`。电阻电容先不框。

**Q：OCR 文字很小、看不清怎么办？**
A：挑能看清的一个写，看不清就不写。真实工业图里丝印通常很清楚，这次合成图有些故意做小了，能写几个算几个。

**Q：为什么对照图里 OK 也有走线？**
A：走线（黄色细线）是 PCB 正常纹理，不算缺陷。缺陷看的是**元件状态**和**额外黑点/划痕**。
