| 文件 | 真值 | 你的标注 | 原因 |

**关键洞察**：3 个错全部集中在 **"缺件 ↔ 偏移"** 这一对。这恰好是真实工业质检里最容易混淆的两类缺陷——

> 偏移 = 元件**在，但没对准**；缺件 = 元件**根本不在，只剩焊盘**。
> 判断口诀：**"先看有没有元件。有但歪=偏移；连元件都没有=缺件。"**

（注：合成图中空焊盘旁保留了元件丝印文字，确实容易让人误以为"元件跑偏了"，所以这 3 个错你有一半责任、有一半是我制图时的视觉歧义，不全是你的锅。）

## 三、标注规范 SOP（可写进简历的产出物）

### 1. 分类判定标准（决策树）
```
第1步：该装元件的位置，元件在吗？
  └ 不在（只有空焊盘）→ 缺件
  └ 在 → 第2步
第2步：元件对准焊盘了吗？
  └ 明显偏离/悬空 → 偏移
  └ 对齐 → 第3步
第3步：板面有不该有的黑点吗？
  └ 有 → 异物
  └ 没有 → 第4步
第4步：板面有划伤灰白线吗？
  └ 有 → 划痕
  └ 没有 → OK
```

### 2. 目标检测框规范
- 框选对象：板上的**黑色芯片元件**、**焊点**
- 框要**贴近元件边缘**，不压字、不漏边
- 一张图可多框（本批平均 3.6 框），全部元件都要框

### 3. OCR 规范
- 识别元件旁的**丝印编号**（如 U1、R5、C1、Q2）
- 格式：直接写字母+数字，如 `Q5`、`R3`
- 看不清可不填，但尽量填

### 4. 验收标准
- 分类准确率 ≥ 95%（本批 90%，缺口在缺件/偏移复核）
- 检测框漏框率 < 5%
- 易混项（缺件 vs 偏移）必须双人/二次复核
